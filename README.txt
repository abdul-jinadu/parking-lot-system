The author argues in his main argument that Ai has sped up the process of coding, yet it still hasn't solved software development fully.
Developers still need to test out code that Ai generates as well as understand and maintain it.\

Ewerlof makes many claims about ai and software development.
Like how Ai can still make mistakes while writing code.
How it can be useful as a tool but a replacement for developers.
And even arguing that more code doesn't always mean better software.

I do personally agree that Ai should be more of a tool instead of a replacemnt,
Although Ai can save plenty of time the programmers still need an understanding of the code and double check that it still works correctly.

I wouldn't say disagree but I do question the whole narrative that Ai is taking over coding.
Is it improving quickly? Yes. But it still has ways to go in the scheme of handling more programming task than Ewerlof espects.
